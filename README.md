# Limore Queue Assistant & Keeper (v1.2 Modern UI)

Aplikasi pendamping khusus untuk pengguna Redmi A2 / Android Go yang sering mengalami masalah antrean Limore Cloud Game reload atau tertutup saat ditinggal.

## ✨ Fitur & Desain Baru (v1.2):
1. **Modern Clean Dark UI + Bottom Navigation (3 Menu)**:
   - 📱 **Tab Antrean (Dashboard)**: Monitor status real-time, kontrol Service, tombol buka Limore cepat, dan matikan alarm.
   - ⚡ **Tab Anti-Kill & Floating**: Integrasi Shizuku 1-Click untuk menonaktifkan pembunuhan background oleh sistem, tombol Bubble Melayang, dan pemaksa Freeform Window.
   - ⚙️ **Tab Pengaturan (Settings)**: Atur Auto-Launch, aktifkan/matikan suara alarm, getar berulang, serta tombol uji coba nada dering.
2. **🌐 Fitur Floating Bubble (Tombol Melayang)**:
   - Menggunakan izin `SYSTEM_ALERT_WINDOW`.
   - Menampilkan ikon bubble bulat melayang yang bisa digeser bebas di atas layar saat Anda sedang membuka aplikasi lain (WA, Browser, dll).
   - Ketuk bubble untuk memunculkan menu cepat: **Buka Limore**, **Matikan Alarm**, atau tutup bubble.
3. **🪟 Fitur Buka Freeform Window**:
   - Membuka Limore secara paksa dalam mode jendela melayang sistem menggunakan perintah Shizuku `--windowingMode 5`.
4. **⚡ 1-Click Shizuku Anti-Kill**:
   - Menjalankan seluruh perintah pembebasan background, Doze whitelist, dan mematikan Phantom Process Killer otomatis.
